# 六艺日课 v1.1

自托管的私人六艺训练记录应用。支持同艺多式训练、历史记录、手机仪表盘、分享图片及数据备份。

## 在Mac mini启动

1. 安装Node.js 24.14或更新的24.x。
2. 下载并解压到固定目录，在终端进入该目录。
3. 运行 `bash 启动-Mac.command`。
4. 在Mac浏览器打开 http://localhost:4177，设置6位数字密码。
5. 从“计划与数据”导入旧电脑导出的JSON。

用户登录后自动运行、手机访问、完整数据迁移及更新方式见[安装与使用](安装与使用.md)。Mac实际运行和网络访问需要在目标设备验证。

应用数据保存在本机，部署包不含个人记录、密码、会话或本机网络配置。更新时保留data、backups和.env。
