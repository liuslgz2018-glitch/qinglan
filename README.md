# 六艺日课 v2.0 · 多用户版

自托管的六艺训练记录应用。每人拥有独立账号、训练记录、计划、仪表盘和导入导出；支持同艺多式训练、手机布局和图片分享。

## Mac mini 安装

1. 安装 Node.js 24.14 或更新的 24.x。
2. 下载并解压到固定目录，在终端进入该目录。
3. 运行 `bash 启动-Mac.command`。
4. 在 Mac 浏览器打开 http://localhost:4177，首次创建管理员账号（账号名可填 owner），设置6位数字密码。
5. 从「计划与数据」导入旧电脑导出的 JSON。

原 v1.x 直接升级时，旧数据和密码自动归入管理员账号 `owner`，旧会话继续有效。升级前服务会创建数据库备份。

## 邀请朋友

管理员登录后进入「计划与数据 → 邀请与账号管理 → 生成邀请码」。将邀请码和可访问的应用地址发给朋友。朋友在登录页选择「邀请加入」，填写独立账号名、6位密码和邀请码。邀请码24小时内有效、只能使用一次。

修改密码在「计划与数据 → 我的账号」。忘记密码时，管理员可生成一次性重置码；用户在登录页选择「忘记密码」使用。修改或重置密码会使该账号的旧会话失效。管理员只能通过网页管理账号，不能查看其他人的训练记录；服务器文件的持有人仍能访问服务器上的数据库。

## 部署和数据

手机使用移动网络、无需安装客户端的公网入口，可参考 [Mac 与 Funnel 部署](Mac与Funnel部署.md)。该文档包含独立 Node.js、登录自启动与公网 DNS 排查；Funnel 显示开启不代表移动网络已经可用，必须完成外网验收。

GitHub只分发程序，服务运行在你的Mac mini上。手机与朋友的访问地址需在Mac部署后配置；Windows临时热点地址不能直接沿用。用户登录后自动运行、HTTPS访问和数据备份见[安装与使用](安装与使用.md)。Mac及朋友的真实设备访问仍需在目标设备验证。

部署包不含任何个人记录、密码、会话、邀请码或本机网络配置。更新保留 `data`、`backups` 和 `.env`。完整迁移必须停服后复制整个 `data` 目录（含子目录），不能只复制一个SQLite文件。

验证：`node --test test/*.test.mjs` 和 `node scripts/check.mjs`。
